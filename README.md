# meu-curriculo-alberto-junior# 
Site de Currículo Pessoal - Alberto Júnior

Bem-vindo ao meu site de currículo pessoal! Este projeto foi desenvolvido para apresentar as minhas informações académicas, competências, projetos, hobbies e formas de contacto.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura e semântica)
- **CSS3** (Estilização, design responsivo e animações)

## 📋 Funcionalidades
- **Página Inicial (Index):** Apresentação pessoal, objetivo e visão.
- **Sobre (About):** Dados pessoais, formação académica e habilidades técnicas com barras de progresso.
- **Portfólio:** Exibição de projetos académicos e pessoais.
- **Hobbies:** Áreas de interesse e atividades extracurriculares.
- **Contacto:** Formulário interativo e informações de contato (email, telefone, redes sociais).
